# Лавка и длинные ники — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** ведущий заводит предметы лавки, открывает её между вопросами и продаёт игрокам за очки; закрытые предметы раскрываются купившему и на ТВ анимацией; длинные ники не обрезаются.

**Архитектура:** состояние лавки — поле `shop` в `GameState`, чистые функции в `server/src/game/shop.ts`, проекции в `views.ts` прячут содержимое закрытых предметов. Сервер добавляет шесть админ-команд, два события (`player:trophies`, `shop:purchased`) и HTTP-загрузку фото. Клиент: раздел «Лавка» в админке, общая витрина для ТВ и телефона, оверлей анимации покупки на CSS + inline SVG.

**Стек:** TypeScript strict, ESM, npm workspaces (`shared`, `server`, `client`), Express 4 + Socket.IO 4, React 18 + Vite 5, Vitest 2.

**Спека:** `docs/superpowers/specs/2026-10-18-shop-design.md`

## Глобальные ограничения

- **Сервер на порту 3000 не запускать и не трогать.** Ручная проверка — только `PORT=3100`, после проверки тестовый сервер остановить (`PORT=3100 ./stop.command`).
- Новых npm-зависимостей не добавлять; анимация — только CSS + inline SVG.
- Валидация предмета: название 1..60 символов после trim, описание ≤ 500, цена — целое 0..100000, количество — целое 1..99, `image` отсутствует или соответствует `^/media/shop/[a-z0-9-]+\.(jpg|png|webp)$`; иначе `INVALID_ITEM`.
- Новые `ErrorCode`: `INVALID_ITEM`, `SOLD_OUT`, `NOT_ENOUGH_POINTS`.
- Содержимое закрытого предмета (`name`, `description`, `image`) не попадает в `state:public` ни при каких условиях.
- Загрузка: `POST /api/shop/image`, заголовок `X-Admin-Pin`, `Content-Type` ∈ `image/jpeg | image/png | image/webp`, лимит 5 МБ; ответы 401 / 415 / 413; файлы в `<mediaDir>/shop/`.
- Лимит ника остаётся 24 символа.
- Тексты интерфейса — на русском, как в спеке («Лавка», «Тайна», «Продано», «Твои трофеи», «{Имя} получает»).
- Проверки после каждой задачи: `npm test`, `npx tsc -p server --noEmit`, `npx tsc -p client --noEmit`.

## Review Focus

1. Цена 0: игроку с 0 очков продажа проходит, игроку со счётом −100 — `NOT_ENOUGH_POINTS` (правило `score < price`). Тест в задаче 2.
2. Правка предмета после продажи: новая цена не меняет возврат при отмене (возвращается `Purchase.price`), уменьшение количества ниже проданного — `INVALID_ITEM`. Тест в задаче 2.
3. Удаление игрока с покупками — покупки исчезают, остаток предмета растёт обратно. Тест в задаче 2.
4. Фото, которое браузер не может декодировать (HEIC в Chrome на ПК), — тост «Не удалось прочитать фото», форма остаётся рабочей, предмет сохраняется без фото. Ручная проверка в задаче 11.
5. 16 предметов в витрине ТВ — все видны на экране без прокрутки, карты мельче. Ручная проверка в задаче 11.
