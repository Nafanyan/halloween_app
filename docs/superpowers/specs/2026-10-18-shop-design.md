# Лавка (магазин) и длинные ники — дизайн

Дата: 2026-10-18. Дополняет [дизайн квиза](2026-10-18-quiz-buzzer-design.md).

## Цель

Между раундами ведущий открывает «лавку»: витрину предметов, которые игроки
покупают за набранные очки. Предметы ведущий заводит сам из админки — фото,
название, описание, цена, количество. Бывают **закрытые** предметы: в витрине
это «тайна» с ценой, содержимое видно только купившему и раскрывается на
телевизоре анимацией в стиле открытки «Сумеречный шабаш».

Попутно — длинные ники перестают обрезаться многоточием.

**Критерии успеха**
- Ведущий за минуту заводит предмет с фото, снятым на телефон.
- Покупка списывает очки ровно один раз; ошибочную покупку можно отменить с возвратом очков.
- Содержимое закрытого предмета не попадает ни в одно сообщение, которое получают не-купившие (проверяется тестом).
- Каталог переживает перезапуск сервера и «Новую игру».
- Ник из 24 символов виден целиком на ТВ (лобби и таблица очков).

**Вне рамок**
- Игрок не покупает сам и не шлёт заявок: покупку оформляет только ведущий.
- Эффекты предметов в игре (предметы — призы/фанты, их смысл обыгрывается вживую).
- Звук анимации покупки.
- Удаление неиспользуемых файлов фото.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Кто оформляет покупку | Только ведущий: «Продать» → выбрать игрока |
| Количество | Задаётся ведущим, по умолчанию 1 |
| Кто видит закрытый предмет | Купивший (телефон) и все на ТВ в момент покупки; в витрине для остальных он остаётся «тайной» |
| «Новая игра» | Предметы остаются, покупки стираются, лавка закрыта |
| Когда открывается | Вручную кнопкой ведущего, когда нет активного вопроса; открытие вопроса закрывает лавку |

## Данные

В `shared/src/types.ts`:

```ts
interface ShopItem {
  id: string; name: string; description: string;
  price: number;      // целое, 0..100000
  quantity: number;   // целое, 1..99
  hidden: boolean;    // закрытый предмет
  image?: string;     // '/media/shop/<uuid>.jpg'
}
interface Purchase { id: string; itemId: string; playerId: string; price: number; at: number }
interface ShopState { open: boolean; items: ShopItem[]; purchases: Purchase[] }
// GameState получает поле shop: ShopState
```

- Остаток = `quantity − число покупок этого предмета`; не хранится, вычисляется.
- `Purchase.price` — цена на момент продажи; отмена возвращает именно её.
- Валидация предмета: название 1..60 символов после trim, описание до 500,
  цена и количество — целые в указанных диапазонах, `image` либо отсутствует,
  либо соответствует `^/media/shop/[a-z0-9-]+\.(jpg|png|webp)$`.
  Нарушение → `INVALID_ITEM`.
- Количество нельзя сделать меньше уже проданного → `INVALID_ITEM`.

Новые `ErrorCode`: `INVALID_ITEM`, `SOLD_OUT`, `NOT_ENOUGH_POINTS`.

**Персистентность.** `shop` пишется в тот же `state.json`. Старый файл без
`shop` загружается с пустой лавкой. При загрузке отбрасываются некорректные
предметы, покупки несуществующих предметов/игроков; `open` сохраняется.

## Логика (чистые функции в `server/src/game/shop.ts`)

- `addItem(s, input, id)` / `updateItem(s, id, input)` / `deleteItem(s, id)`.
  Удаление убирает и покупки этого предмета (очки не возвращаются; клиент
  спрашивает подтверждение, если предмет уже покупали).
- `setShopOpen(s, open)`: открыть можно только в фазе `game` и без активного
  вопроса (`WRONG_PHASE` / `QUESTION_ACTIVE`); закрыть — всегда.
- `sellItem(s, itemId, playerId, purchaseId, now)`: `NOT_FOUND`, `SOLD_OUT`,
  `NOT_ENOUGH_POINTS` (если `score < price`); иначе списывает цену и добавляет покупку.
  Продавать можно и при закрытой лавке (на случай «продай мне после игры»).
- `cancelPurchase(s, purchaseId)`: возвращает очки игроку, удаляет покупку.
- Изменения существующей логики: `openQuestion` ставит `shop.open = false`;
  `removePlayer` удаляет покупки игрока; `newGame` очищает покупки и закрывает
  лавку, предметы сохраняет; `initialState` — пустая лавка.

## Проекции и события

**Публичная проекция** (`PublicView.shop`), уходит всем:

```ts
interface PublicShopItem {
  id: string; hidden: boolean; price: number; quantity: number; remaining: number;
  name?: string; description?: string; image?: string;  // для hidden — отсутствуют
}
shop: { open: boolean; items: PublicShopItem[] }
```

**Админская проекция** (`AdminView.shop`): полные предметы с `remaining` и
список покупок `{ id, itemId, itemName, playerId, playerName, price, at }`,
новые сверху.

**Личные трофеи.** Событие `player:trophies` (в комнату `player:<id>`) — полный
список купленных предметов игрока `{ purchaseId, item: ShopItem }[]`. Шлётся
при входе/возобновлении и после каждого изменения, затрагивающего лавку или игроков.

**Анимация покупки.** Событие `shop:purchased` с
`{ purchaseId, playerName, item: ShopItem }` отправляется в комнату `screen` и
в комнату купившего. Не сохраняется и не переигрывается при переподключении.

**Новые команды админа** (все с `Ack`, требуют авторизации):
`admin:shopOpen {open}`, `admin:itemAdd {item}`, `admin:itemUpdate {id, item}`,
`admin:itemDelete {id}`, `admin:sell {itemId, playerId}`, `admin:cancelPurchase {purchaseId}`.

## Загрузка фото

`POST /api/shop/image`, заголовок `X-Admin-Pin`, тело — сырые байты картинки,
`Content-Type` одно из `image/jpeg`, `image/png`, `image/webp`; лимит 5 МБ.
Ответ `{ url: '/media/shop/<uuid>.<ext>' }`. Ошибки: неверный PIN → 401,
другой тип → 415, больше лимита → 413. Файлы — в `<mediaDir>/shop/`
(в `.gitignore`).

Перед отправкой админка уменьшает фото в браузере (canvas) до 1200 px по
длинной стороне и кодирует в JPEG ~0.85 — снимок с телефона весит ~200 КБ.

## Интерфейс

**Админка — раздел «Лавка»** (под игроками):
- Кнопка «Открыть лавку» / «Закрыть лавку» (недоступна при активном вопросе).
- Форма предмета: фото (`<input type="file" accept="image/*">` — на телефоне
  предлагает камеру), превью, название, описание, цена, количество,
  переключатель «Закрытый». Та же форма для редактирования.
- Список предметов: миниатюра, название (у закрытых — значок замка), цена,
  «осталось N из M», кнопки «Продать», «Изменить», «Удалить».
- «Продать» раскрывает выбор игрока (с текущими очками; кому не хватает —
  неактивно) и кнопку подтверждения.
- Журнал покупок: «Вася — Кривое зеркало — 300», кнопка «Отменить».

**Телевизор** — пока `shop.open` и нет активного вопроса, вместо сетки вопросов
витрина «Лавка»: сетка карт-таро (фото, название, цена, «осталось N»).
Закрытый предмет — рубашка карты: золотой орнамент, крупный «?», подпись «Тайна»
и цена. Распроданный — притушен с надписью «Продано». Таблица очков остаётся внизу.

**Телефон игрока** — пока лавка открыта и нет активного вопроса, вместо кнопки
та же витрина (только просмотр), сверху блок «Твои трофеи». Вне лавки трофеи —
свёрнутый блок под кнопкой (если есть хоть один).

## Анимация покупки (ТВ, ~7 с)

Мотивы из открытки: тьма, вороны, качание фонаря, искры, лучи, золотая вспышка.
Только CSS-анимации и inline SVG, без библиотек.

1. **0–1 с, тьма.** Полноэкранная вуаль темнеет до ~90%. Пара воронов (SVG-силуэты
   с машущими крыльями `scaleY`) пролетает по дуге слева направо.
2. **1–3,5 с, карта.** Сверху опускается карта-таро рубашкой вперёд (орнамент;
   у закрытого предмета — «?»), с медленным покачиванием ±6° как фонарь.
   Снизу поднимаются искры (15–20 точек с разной задержкой), рамка «дышит» свечным свечением.
3. **3,5–4,5 с, вспышка.** Лучи расходятся из-за карты, золотая вспышка на весь
   экран; карта переворачивается (`rotateY 180°`, `backface-visibility`) лицом:
   фото, название, описание. Над картой вязью (Great Vibes): «{Имя} получает».
4. **4,5–6,5 с** — держим, золотая пыль медленно оседает.
5. **6,5–7 с** — всё растворяется, под ним снова витрина.

- Несколько покупок подряд — очередь, по одной анимации.
- `prefers-reduced-motion` — карта сразу лицом, плавное появление и исчезновение.
- На телефоне купившего — та же последовательность шагов 2–5 в миниатюре
  (без воронов), после чего предмет в «Твоих трофеях».

## Длинные ники

- Таблица очков на ТВ: короткие имена переносятся максимум на 2 строки
  (`overflow-wrap: anywhere`, `text-wrap: balance`, ширина плашки до 24vw)
  вместо `nowrap` + многоточия; имена длиннее 14 символов — шрифт 0.75em,
  до 3 строк, ширина плашки до 26vw.
- Лобби на ТВ: имена переносятся внутри колонки; маркер «✶» с неразрывным
  пробелом, вторая строка с отступом под ним.
- Лимит ника — по-прежнему 24 символа.

## Тестирование

- `shop.ts`: добавление/правка/удаление, валидация, остатки, `SOLD_OUT`,
  `NOT_ENOUGH_POINTS`, отмена с возвратом цены на момент продажи, уменьшение
  количества ниже проданного, `newGame`, `removePlayer`, `openQuestion` закрывает лавку.
- Проекции: в `toPublicView` у закрытого предмета нет `name/description/image`
  (проверка по сериализованному JSON — секретной строки в нём нет).
- Персистентность: старый `state.json` без `shop`; мусорные покупки отбрасываются.
- Сервер: загрузка фото с PIN/без PIN/неверный тип; `admin:sell` рассылает
  `shop:purchased` экрану и купившему, `player:trophies` — только купившему.
- Ручная проверка в браузере — на отдельном тестовом порту (не 3000), тестовый
  сервер останавливается после проверки.
