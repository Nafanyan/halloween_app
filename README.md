# Сумеречный шабаш — квиз с кнопками

Своя игра для вечеринки в локальной сети: большой экран (ТВ), телефоны игроков как кнопки, ведущий управляет с админ-страницы. Работает без интернета.

## Запуск

Проще всего: двойной клик по `start.command` в Finder (или `./start.command` в терминале). Скрипт при первом запуске ставит зависимости, запускает сервер с PIN ведущего `1234` и не даёт Mac уснуть, пока сервер работает. Остановить: `Ctrl+C` в окне терминала. Другой PIN: `ADMIN_PIN=4242 ./start.command`.

Остановить уже работающий сервер (например, если окно терминала закрыто или потерялось): двойной клик по `stop.command` или `./stop.command`. Скрипт гасит только сервер квиза на порту 3000 (другой порт: `PORT=3001 ./stop.command`), игроки и очки сохраняются.

Вручную то же самое:

```
npm install
npm start
```

`npm start` собирает клиент и запускает сервер. В консоли напечатаются адреса и PIN админа:

- **ТВ / большой экран:** `http://<IP-Mac>:3000/screen` — открыть в браузере на телевизоре, развернуть на весь экран. В лобби на нём показан QR-код: игроки сканируют его телефонами и вводят имя.
- **Ведущий:** `http://<IP-Mac>:3000/admin` — вход по PIN.
- **Игроки:** отсканировать QR-код с ТВ (адрес `http://<IP-Mac>:3000/`).

Все устройства должны быть в одной Wi-Fi сети.

## Настройки (переменные окружения)

- `PORT` — порт, по умолчанию `3000`.
- `ADMIN_PIN` — PIN админа. Если не задан, при каждом старте генерируется случайный и печатается в консоль. **На вечеринке задайте его явно:** случайный PIN меняется при каждом перезапуске сервера, и ведущего выкидывает из админки.
- `HOST_IP` — IP-адрес Mac, который попадёт в QR-код и ссылки. По умолчанию берётся адрес интерфейса `en0` (Wi-Fi на Mac), иначе первый внешний IPv4. При старте в консоль печатаются все IPv4-адреса с именами интерфейсов — если QR-код ведёт не туда (VPN, Ethernet, виртуальные сети), перезапустите с нужным адресом.

```
PORT=3123 ADMIN_PIN=1234 HOST_IP=192.168.1.20 npm start
```

## Игры

Каждая игра — отдельная папка в `server/data/games/<id>/` (`<id>` вида `g-` + 8 символов `a-z0-9`):

```
server/data/games/g-ab12cd34/
  game.json      настройки, вопросы и магазин игры
  media/         картинки и музыка этой игры (без подпапок)
```

Создавать, копировать, удалять игры, менять название, фон, музыку лобби, штраф за неверный ответ, стартовые очки и магазин можно на вкладке «Игры» в админке. Редактора вопросов пока нет: вопросы правятся руками в `game.json` нужной игры. Порядок такой: остановите сервер, отредактируйте `game.json`, запустите сервер снова. Не правьте файл при работающем сервере — любое сохранение из админки (настройки, магазин) перезапишет `game.json` и ваши правки пропадут. Учтите также, что при запуске сервер удаляет из `media/` файлы, на которые не ссылается `game.json`.

```json
{
  "version": 1,
  "title": "Сумеречный шабаш",
  "subtitle": "Наведи телефон на знак — и входи в лес",
  "description": "",
  "lobbyMusic": "dark-forest.mp3",
  "background": "fon.jpg",
  "scoring": { "wrongPenalty": false, "startScore": 0 },
  "rounds": [
    {
      "name": "Раунд 1",
      "themes": [
        {
          "name": "Баба Яга",
          "questions": [
            { "value": 100, "text": "Вопрос", "answer": "Ответ" },
            { "value": 200, "text": "С картинкой", "answer": "Ответ", "image": "izbushka.svg" },
            { "value": 300, "text": "С музыкой", "answer": "Ответ", "audio": "dark-forest.mp3" }
          ]
        }
      ]
    }
  ],
  "shop": [
    { "id": "item-1", "name": "Предмет", "description": "", "price": 100, "quantity": 1, "hidden": false, "image": "item.jpg" }
  ]
}
```

- `title` — 1–60 символов, `subtitle` — до 120 (показывается в лобби на ТВ, может быть пустым), `description` — до 500 (только для админки).
- `lobbyMusic`, `background`, `image`/`audio` вопросов и `image` предметов — необязательные имена файлов из `games/<id>/media/` (без подпапок); файл обязан существовать. Без `background` на ТВ используется встроенный гобелен. Файлы отдаются по `/games/<id>/media/<имя>`.
- `scoring.wrongPenalty` — при `true` неверный ответ снимает номинал вопроса; `scoring.startScore` — целое 0–100000, стартовые очки игрока.
- `value` — положительное целое (очки), `text` и `answer` — непустые строки. Правильный ответ видит только админ.
- Ошибка в `game.json` не роняет сервер: игра остаётся в списке как «битая» с указанием поля, её нельзя запустить, пока ошибка не исправлена.

**Миграция.** При первом запуске после обновления (если папки `games/` ещё нет) старые `server/data/questions.json` и предметы магазина автоматически переносятся в первую игру «Сумеречный шабаш»; игроки, очки и покупки сохраняются. Сам `questions.json` остаётся на месте как резервная копия и больше не читается.

**Перенос игры.** Скопируйте папку `server/data/games/<id>/` целиком на другой компьютер в такую же папку — после перезапуска сервера игра появится в списке.

`server/data/games/` содержит пользовательские данные и добавлена в `.gitignore`.

В примере: `dark-forest.mp3` — «Dark Forest Theme», cynicmusic, CC0 (общественное достояние); `izbushka.svg` нарисован специально для проекта.

Оформление повторяет приглашение «Сумеречный шабаш»: фон — гобелен И. Я. Билибина (1901, общественное достояние), шрифты Yeseva One, Cormorant Garamond и Great Vibes (SIL Open Font License, вшиты в сборку, интернет не нужен).

## Сброс игры

Состояние хранится в `server/data/state.json` (пишется после каждого действия, переживает перезапуск сервера). Сбросить:

- кнопкой «Новая игра» на странице админа, либо
- остановить сервер и удалить `server/data/state.json`.

Сброс затрагивает только прогресс вечера (игроки, очки, покупки); игры в `server/data/games/` не удаляются. Активная игра при этом запоминается в `state.json`; если его удалить, активной станет первая исправная игра.

## Советы для вечеринки

- Задайте `ADMIN_PIN` (см. выше), чтобы перезапуск сервера не менял PIN.
- Запретите Mac засыпать: `caffeinate -dis` в соседнем терминале (или Системные настройки → Экран / Энергосбережение) и не закрывайте крышку ноутбука.
- Если телефоны не открывают адрес: Системные настройки → Сеть → Брандмауэр — разрешите входящие подключения для `node` (или временно отключите брандмауэр).
- Проверьте, что телефон и Mac в одной сети (не в гостевой Wi-Fi с изоляцией клиентов).
